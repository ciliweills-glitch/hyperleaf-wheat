# 仿真与实测结果

本工程采用四层2DCNN。以下结果来自各次软件比较、RTL仿真和AX7020上板测试。

## 数值比较

样本00001的四层卷积、池化和GAP输出与软件整数参考逐元素一致，最大差为0 LSB。最终PhiPSII预测为0.6990。

10月29日从独立工程目录运行十张原始TIFF，每张完成316条命令，状态为0。板端直接回放和PC网口回放的预测值与整数参考最大绝对差均为2.54×10⁻⁸。

当前RTL的15组事务测试比较了16,312个输出字、72,560个池化前数值和21,012个预处理字，均与预期一致。测试包含四层配置、边界补零、奇数输入通道、RAW预处理，以及输出等待时的数据保持。

## 400张连续检测

400张原始TIFF经网口输入，全部完成预测。总用时529.094秒，平均板端推理1.321秒，平均输入准备0.227秒。各阶段因准备与计算重叠而分别计时。

## 资源与时序

完整LCD与CNN工程使用11,372个LUT、14,176个FF、78块BRAM36等效资源和62个DSP。CNN时钟为100 MHz。当前约束覆盖的路径建立裕量为1.039 ns，保持裕量为0.042 ns，TNS和THS均为0，DRC为0违规。

ROSS复查发现，裕量最小的建立路径位于VTC复位控制网，布线延迟占94.17%。CNN内裕量最小的路径位于F48输出，建立裕量为1.068 ns。28个LCD输出还需按面板和板线补充外部延迟约束。

